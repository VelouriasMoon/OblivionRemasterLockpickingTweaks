# Oblivion Remaster Lockpicking Tweaks
Reworks how the Security skill factors into the lockpicking minigame.

### Overview
How Security skill factors into lockpicking in the vanilla game is honestly kinda useless, at Apprentice 3 tumblers will fall, Journeyman 2, Expert 1. However these numbers are how many will ALWAYS fall, meaning that Apprentice you won't see any improvement to the minigame until a very hard lock on the last tumbler if you mess up, leaving one tumbler still locked in, messing up again before getting back to the last tumbler will reset the whole lock again.  

With this mod each skill milestone will allow 1 tumbler to stay locked in no matter how many times you fail. So Apprentice you get one tumbler to stay locked in, Journeyman 2, Expert 3, this adds, in my opinion, a much more gradual and noticable improvement to the minigame at the lower levels of the skill and with weaker locks without restoring to cheesing or the skeleton key.
